# 兒科門診衛教室

給家長看的兒科常見問題衛教網站，也附醫師在門診可快速查詢的用藥參考。

- 首頁：依分類列出衛教主題，可用關鍵字搜尋；另有「醫師專區」索引
- 已完成主題：
  - `otitis-media.html` 兒童中耳炎與中耳積液：成因圖解、耳鏡照片、症狀、居家照顧、回診時機、預防；醫師參考含診斷標準、抗生素或觀察、常見致病菌、抗生素種類與劑量、療程、治療失敗、OME 處置與參考文獻

## 新增主題

1. 複製 `otitis-media.html` 為新檔案並改寫內容
2. 在 `js/common.js` 的 `CATEGORIES` 中，替該主題補上 `url`（以及醫師參考用的 `doc`、`docTitle`）
