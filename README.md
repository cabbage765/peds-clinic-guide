# 兒科門診衛教室

給家長看的兒科常見問題衛教網站，也附醫師在門診可快速查詢的用藥參考。

- 首頁：依分類列出衛教主題，可用關鍵字搜尋；另有「醫師專區」索引
- 已完成主題：
  - `otitis-media.html` 兒童中耳炎與中耳積液：成因圖解、耳鏡照片、症狀、居家照顧、回診時機、預防；醫師參考含診斷標準、抗生素或觀察、常見致病菌、抗生素種類與劑量、療程、治療失敗、OME 處置與參考文獻
  - `croup.html` 哮吼：聲門下腫脹解剖圖、幼兒與大人氣道水腫比較、喘鳴聲音、症狀、居家照顧、就醫警訊、預防；醫師參考含近五年實證重點、嚴重度分級與 Westley score、致病原、依嚴重度處置、類固醇與 epinephrine 劑量、留觀與住院條件、鑑別診斷、參考文獻
  - `allergic-rhinitis.html` 過敏性鼻炎：鼻腔發炎圖、過敏機轉、塵蟎與常見過敏原、症狀與外觀、與感冒的區別、治療總覽；類固醇鼻噴劑、生理食鹽水噴霧、海鹽鹽水洗鼻三種方法的圖解與使用訣竅；居家防塵蟎；醫師參考含 ARIA 分類、鑑別診斷、階梯治療、藥物劑量、減敏治療、共病與轉介
  - `enterovirus.html` 腸病毒：疱疹性咽峽炎與手足口病照片、病程時間軸、重症前兆、肌躍型抽搐影片、居家照顧、洗手與漂白水消毒、EV71 疫苗；醫師參考含型別與表現、診斷與通報、重症分期與處置、新生兒腸病毒、疫苗實證
  - `uti.html` 泌尿道感染：細菌上行示意圖、危險因子、各年齡症狀、驗尿方法、治療、膀胱輸尿管逆流機轉與分級圖、檢查說明、預防；醫師參考含診斷、抗生素劑量、療程、影像建議、VUR 分級與 VCUG 影像（第 III、IV、IV–V 級）、預防性抗生素
